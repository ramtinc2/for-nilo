# سورپرایز عاشقانه برای نیلو ♡

یک وب‌سایت استاتیک فارسی، راست‌چین و واکنش‌گرا؛ آماده‌ی انتشار رایگان روی GitHub Pages.

## انتشار روی GitHub Pages

1. وارد GitHub شو و یک مخزن جدید بساز (مثلاً `for-nilo`).
2. فایل‌های `index.html`، `style.css` و `script.js` را در ریشه‌ی مخزن آپلود کن.
3. از بخش **Settings → Pages**، قسمت **Build and deployment** را روی **Deploy from a branch** بگذار.
4. شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب و Save کن.
5. بعد از چند دقیقه لینک سایت در همان صفحه نمایش داده می‌شود؛ معمولاً به شکل:
   `https://USERNAME.github.io/for-nilo/`

## شخصی‌سازی سریع

- متن‌ها در `index.html` هستند؛ می‌توانی جمله‌ها را مطابق حرف دل خودت تغییر بدهی.
- رنگ‌ها و ظاهر در `style.css` هستند.
- فایل موسیقی دلخواه و مجاز خودت را با نام `music.mp3` کنار `index.html` قرار بده. سایت هنگام باز شدن تلاش می‌کند موسیقی را خودکار پخش کند؛ بعضی مرورگرها به‌دلیل محدودیت autoplay، پخش صدا را تا اولین لمس یا کلیک کاربر متوقف می‌کنند. در این پروژه با اولین تعامل کاربر، پخش دوباره تلاش می‌شود و هیچ دکمه‌ی روشن/خاموشی وجود ندارد.
- فعلاً سایت بدون عکس طراحی شده و برای موبایل هم بهینه است.

## نکته
این پروژه هیچ بک‌اند، فرم ارسال اطلاعات یا ردیابی ندارد. پاسخ دکمه‌ها فقط روی همان صفحه نمایش داده می‌شود.
